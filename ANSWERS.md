1. Почему heroesCreated должно быть статическим?
Потому что это общее количество созданных героев для всех объектов,
а не отдельное значение каждого героя.

2. Почему name, health и level не должны быть статическими?
Потому что у каждого героя свои имя, здоровье и уровень.

3. Почему printHeroesCreated() можно вызвать без создания объекта?
Потому что метод статический и принадлежит классу, а не объекту.

4. Можно ли из статического метода напрямую обратиться к нестатическому полю name?
Нет, потому что нестатическое поле принадлежит объекту,
а статический метод вызывается без объекта.

5. Почему проект перестанет компилироваться, если убрать final у MAX_LEVEL?
Не перестанет. Но значение MAX_LEVEL можно будет изменять,
хотя оно должно быть константой для всей игры.

6. Почему при вызове метода attack() вызывается версия конкретного наследника?
Из-за полиморфизма и переопределения методов.
Java определяет реализацию метода по реальному типу объекта.

7. Почему переменная knight имеет модификатор final, но её поля могут изменяться?
final запрещает изменять ссылку на объект,
но не запрещает менять состояние самого объекта.
